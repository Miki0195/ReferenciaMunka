# TravelAgency.Angular

## Quick Start Guide

1. Install [Node](https://nodejs.org/).
2. Install project dependencis: `npm install`
3. Run development server: `npm start`

## Google Maps integration

If you want the Google Map to work:

1. Create `src/environments/environment.development.ts`, based on `src/environments/environment.ts`, 
   if it does not exits.
2. Provide your Google Maps API key in `src/environments/environment.development.ts`.
